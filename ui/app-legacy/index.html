    AA History

    Every AA rank purchase this session, from the log's own "gained the ability"/"improved" lines. Buying an AA is gated on your active trio at the time, but a purchase never gets undone by a later loadout swap -- so an ability tagged for a class you're not currently playing is a past build, not a mistake. Cross-referenced against the Character tab's active classes and your confirmed class history.

    Spellbook

    Every spell confirmed known this session, from the log's own "You have finished memorizing X." lines. EQL has no separate "scribed into spellbook" event, but a spell can only complete memorization if it's already known -- so this is exactly as good a proof as a scribe line would be. A spell you own but never once memorized this session won't show up here yet.
